# Diversifi API Docs

This repository publishes the production API reference to Scalar.

The dev Scalar site remains in the Kubernetes cluster at `dev-docs.diversifi.ai`. Its OpenAPI source is the static artifact published by the backend pipeline at `https://dev-docs-openapi.diversifi.ai/openapi.json`.

See [RUNBOOK.md](RUNBOOK.md) for the publication flow and rollback procedure.
